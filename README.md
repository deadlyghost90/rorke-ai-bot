# Rorke Bot 🤖

AI-powered Minecraft bot with Hugging Face model switcher!

## Features
- 🤖 AI Chat (8+ models)
- 🔄 Model Switcher (!model)
- 👋 Welcome/Goodbye messages
- 💬 Auto AI response

## Commands
| Command | Description |
|---------|-------------|
| !help | Show commands |
| !ping | Check bot latency |
| !info | Show current model |
| !models | List all models |
| !model <name> | Switch AI model |
| !ai <question> | Ask AI anything |

## Available Models
- mistral (default)
- llama
- gemma
- phi
- zephyr
- falcon
- tinyllama
- qwen

## Environment Variables
- SERVER_IP: Minecraft server IP
- SERVER_PORT: Server port
- HF_TOKEN: Hugging Face API token
- DEFAULT_MODEL: Default AI model
